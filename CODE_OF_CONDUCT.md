# Code of Conduct

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, and keep discussion focused on the project.
Harassment, personal attacks, and discriminatory language are not welcome.
Maintainers may edit or remove contributions that violate these norms.

Report concerns privately to the maintainer via GitHub.
